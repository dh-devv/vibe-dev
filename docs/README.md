# 📂 Docs

이 폴더는 **BAO 프로젝트의 핵심 명세서 및 설계를 관리하는 문서 창고**입니다.  
개발 진행 전 모든 팀원(FE/BE/DB)은 이 폴더의 명세서를 기준으로 코드를 작성합니다.

---

## 📑 관리 문서 목록

| 문서 파일 | 역할 및 내용 | 담당자 |
| :--- | :--- | :---: |
| **`API_SPEC.md`** | 프론트엔드-백엔드 간 HTTP 통신 규칙 (URL, Method, Req/Res Data) | 김승운 / 이채혁 |
| **`DATABASE_SPEC.md`** | MySQL 테이블 스키마, 컬럼 타입 및 관계(ERD) 정의 | 최성은 |
| **`DEVELOPMENT_RULES.md`** | 코딩 컨벤션, AI 개발 공통 지시사항 | 변동헌 |

---

## ⚠️ 문서 작성 및 변경 규칙

1. **사전 확정 후 개발:**  
   코드를 작성하기 전 `API_SPEC.md`와 `DATABASE_SPEC.md` 작성을 완료하고 공유합니다.
2. **임의 변경 금지:**  
   개발 진행 중 API 주소나 데이터 형식이 변경되어야 할 경우, **문서를 먼저 수정**한 뒤 팀원 및 담당 AI에게 공유하고 코드를 수정합니다.
3. **명세 준수:**  
   AI를 활용한 코드 생성 시, 반드시 이 폴더의 명세서 규격을 지키도록 지시합니다.
